# 超级玛丽 · 蘑菇王国大冒险 2

一款可离线游玩的中文像素平台游戏。四个世界、八个长关卡各有一间管道密室。可以一路冲旗比拼分数，也可以沿藤蔓、斜坡和升降台探索积分星。所有关卡均可从大厅直接进入。

## 开始冒险

解压后打开 `index.html`，点击「开始冒险」。想直接挑战库克，可以在「熔岩城堡」里选「4-2 库克的王座」。脚本、图像、字体与音乐都在包内。

| 动作 | 键盘 | 触屏 |
| --- | --- | --- |
| 移动 | ← → 或 A / D | 左右方向键 |
| 跳跃 | 空格或 J，按住跳得更高 | 跳跃键 |
| 加速 | 移动时按住 Shift 或 K | 跑 |
| 蹲下、蹲行 | 按住 ↓ 或 S，配合左右穿低廊 | 下方向键配合左右 |
| 进入密室、回到主路 | 站在带箭头的管口中央，按住 ↓ 或 S | 按住下方向键 |
| 攀藤 | 靠近藤蔓按 ↑ 或 W，上下攀爬，按跳跃离藤；离开藤蔓也可用 ↑ 起跳 | 上、下、跳跃 |
| 发射火球 | 火焰形态按 X 或 F，可按住连续发射 | 火球 |
| 暂停 / 继续 | Esc 或 P | 暂停键 |

手机可同时按方向和动作键。离开游戏窗口会自动暂停。大厅和暂停界面都能返回选关。

## 四个世界

| 世界 | 关卡 | 可探索的路线 |
| --- | --- | --- |
| 青葱草甸 | 初晴小径、弹簧花园 | 从初晴小径的问号砖先后取得蘑菇与火焰花。沿箭头进地窖，或留在地面蹲过花管后的低廊，再攀上树冠。 |
| 辉光晶洞 | 蓝晶摆渡、回声矿道 | 沿地下主路跑过晶床，也可搭升降台、跳过碎台，寻找高处的矿仓和积分星。 |
| 云顶风车 | 风车邮路、落日云梯 | 借风车上的弹簧与长藤换层，在飞龟巡逻的上方寻找空中平台。 |
| 熔岩城堡 | 熔炉巡廊、库克的王座 | 绕过旋转火杆，到竞技场前点亮中途旗。库克会吸气喷火、蓄势冲锋，撞墙眩晕后可踩头或用火球命中。获胜后上旗阶冲击最高旗分。 |

休闲、经典、专家模式的起始体力分别为 5、3、2 颗心，库克分别需要 3、4、5 次有效命中。更高难度会增加巡逻敌人、提高敌人速度、缩短碎台停留时间与通关时限。每关有两至三面中途旗。

## 道具、得分和存档

- 蘑菇把小马里奥变大。超级和火焰形态能顶碎普通砖。火焰花可直接变身，发出的火球会沿地面弹跳，同时最多两发。受伤依次从火焰退回超级、小马里奥，再消耗体力。
- 蓝色积分星每枚 **1000 分**。主路和密室都有，每枚只计一次。彩虹金色无敌星藏在少数问号砖中，**持续 10 秒**，可以直接撞倒巡逻怪和食人花。落坑和时限仍然有效。
- 每枚金币 100 分，顶碎普通砖 50 分。踩敌时保持腾空能把连击从 100 分逐步提高到 8000 分，踢出的龟壳也能累积连击。
- 触旗按高度计 100、400、800、2000 或 5000 分。滑下旗杆后，计时器上每剩 **1 秒加 50 分**。结算列出冒险得分、旗分、余时和整段行程的总分。
- 钻管往返会保留两边的道具和得分。体力耗尽或时间到后，可在最近点亮的中途旗重试，恢复当时的分数、道具与剩余时间。
- 选「进入下一关」会带上形态与累计得分。从大厅单独选关会开始新的计分行程。通关后，本浏览器会保存已发现的密室、积分星位置、各难度单关最高分、最快用时和行程最高分。新版独立记录，沿用旧版的难度和声音偏好。

## 发布到 GitHub Pages

1. 解压 GitHub Pages 发布包，把 `index.html`、`style.css`、`js/`、`assets/`、`.nojekyll` 和说明文件放入仓库的 `main` 分支根目录。
2. 在仓库 **Settings → Pages → Build and deployment** 中选择 **Deploy from a branch**。
3. 选择 **main** 与 **/(root)**，保存设置，等该页出现 **Visit site** 后即可打开游戏。

站点免构建，资源使用相对路径，可以部署在仓库子路径下。[GitHub Pages 官方设置说明](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## 本版制作提示词

> 设计八个能竞速，也值得回头探索的马里奥关卡。第一关用一块蘑菇砖、一朵火焰花和一条能蹲行的低廊教会三个动作。让金币指向安全落点，让稀有无敌星、藏在藤顶的蓝星和高位旗分奖励不同玩法。每间密室都有能认出的入口和下游出口。高难要增加敌人的组合，库克的火焰和冲锋要给玩家看招、躲招、反击的机会。

参考所给 TAS 视频中约 0:15 的地下金币室、约 4:02 的高位触旗与其后的计时结算，以及约 4:40 的旋转火杆。采用素材库中的地上、地下、城堡和无敌主题。素材来源、录音标识与发布授权情况见[素材说明](./CREDITS.md)。
