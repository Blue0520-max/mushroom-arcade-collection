# 超级玛丽 · 蘑菇王国大冒险 V4

V4 是基于 V3 的增强版。沿树冠跑过花田，换船穿过晶湖，再借风登上炮舰。四个世界共八关，均可从大厅直接进入，也可离线游玩。

## 开始冒险

解压后打开 `index.html`，点击「开始冒险」。想直接挑战库霸，可以在「熔岩城堡」里选「4-2 库霸的王座」。脚本、图像、字体与音乐都在包内。

| 动作 | 键盘 | 触屏 |
| --- | --- | --- |
| 移动 | ← → 或 A / D | 左右方向键 |
| 跳跃 | 空格或 J，按住跳得更高 | 跳跃键 |
| 加速 | 移动时按住 Shift 或 K | 跑 |
| 蹲下、蹲行 | 按住 ↓ 或 S，配合左右穿低廊 | 下方向键配合左右 |
| 进入密室、回到主路 | 站在带箭头的管口中央，按住 ↓ 或 S | 按住下方向键 |
| 攀藤 | 靠近藤蔓按 ↑ 或 W，上下攀爬，按跳跃离藤，也可在离藤时用 ↑ 起跳 | 上、下、跳跃 |
| 火球／骑龙吞敌 | X 或 F，按住可连续使用 | 火球／吞敌 |
| 下龙 | 按住 ↓ 再按 X | 同时按下方向与吞敌 |
| 暂停 / 继续 | Esc 或 P | 暂停键 |

手机可同时按方向和动作键。离开游戏窗口会自动暂停。大厅和暂停界面都能返回选关。

## 八条路线

选关卡片会展示本关的地形剖面和当前难度的时限。表内时间单位为秒。

| 关卡 | 路线 | 休闲 | 经典 | 专家 |
| --- | --- | ---: | ---: | ---: |
| 1-1 花田岔路 | 在田埂上学习蘑菇、火焰花与钻管，再选择地面或树冠绕过溪谷。 | 182 | 123 | 50 |
| 1-2 弹簧果园 | 在不同高度的果棚间用弹簧接力，避开守桥的锤子兄弟，抵达树上的终点。 | 198 | 134 | 53 |
| 2-1 晶湖渡船 | 在码头等船靠岸，换乘渡船跨过三片开阔水面。中途小岛可以停脚。 | 226 | 153 | 72 |
| 2-2 倒悬矿井 | 前往井底，攀藤后向左沿高梁折返。碰到琥珀开关，再回矿门继续上行。 | 223 | 151 | 63 |
| 3-1 乘风邮路 | 跳进有上升条纹的风柱，借风换到高层云道。留意追着马里奥投卵的云龟。 | 207 | 140 | 51 |
| 3-2 炮舰编队 | 从高处出发，在八艘悬空炮舰的甲板与船舱间换层。整段船队下方都是高空。 | 225 | 152 | 54 |
| 4-1 双闸熔炉 | 先到炉顶碰琥珀开关，再从检修道右侧折回，碰水蓝开关。颜色与闸门的单杠、双杠一一对应。 | 243 | 164 | 60 |
| 4-2 库霸的王座 | 穿过护城壕与炮楼，取战前补给，点亮中途旗，再进王座庭院迎战库霸。 | 274 | 185 | 88 |

八关各有独立的管道密室，主路和密室共藏有 **131 枚蓝色积分星**。三颗金色无敌星分别藏于 1-1、2-2 和 4-1。休闲、经典、专家的起始体力分别为 5、3、2 颗心。难度也会改变巡逻增援、投射间隔、炮速和碎台停留时间。专家时限逐关按实测路线设定，渡船关包含等船和换乘时间，王座关包含整场首领战。

## 敌人的动作和破绽

- **锤子兄弟**会短跳巡逻。举锤时已选好方向，抛出的锤子呈弧线下落。可以从上方踩头，或用火球击败它。
- **刺龟**背上的尖刺会扎伤跳踩的马里奥。火球、滑动的龟壳和无敌星都能对付它。
- **云龟**会沿邮路长距离追击，还会跟着玩家改变高度。看到它把刺卵举过头，要留意下方落点。卵在碰到的第一层砖、甲板或地面孵化，落地前可用火球打掉。借高处踩中云龟可得至少 800 分。
- **炮弹塔**现在更频繁地开火。炮口闪光后会平射，紧贴炮塔会止射。可以跳踩炮弹借力上升。
- **炸弹龟**会快速冲向马里奥，接近或被踩时点燃引信。闪光后赶快跳开，或先用火球、滑动龟壳从远处引爆。未骑龙时，被炸到会按当前形态退化或掉体力。
- **鬼火**从熔岩直线跃起，落回去后会停一会儿。城堡里的旋转火球也增加了一节，先看清最外端经过的位置再跳。
- **库霸**会吸气连喷高低火焰、瞄准重跳和蓄力冲锋。高焰可蹲，低焰要跳。地面标记预告起跳落点，库霸落地或撞墙冒星时可以踩头或用火球还击。三档分别需要 3、5、6 次有效命中。专家还有空中吐火，错过落地破绽时可能接着再跳。

## 道具、得分和存档

- 先吃蘑菇变成超级形态，才能吃火焰花。小马里奥碰到的火焰花会留在原地。火球会沿地面和斜坡弹跳，撞到实体墙会熄灭，同时最多两发。受伤依次从火焰退回超级、小马里奥，再消耗体力。
- 顶有龙蛋标记的金币砖可以放出宠物洞穴龙。花田岔路起点附近就有一块。跳到龙背上骑乘，按 X 或 F 吞下正前方的小怪。遇袭时龙会替你挡一次伤害，然后受惊跑开，追上后可以再骑。钻管和攀藤前会自动下龙。
- 蓝色积分星每枚 **1000 分**。主路和密室都有，每枚只计一次。彩虹金色无敌星藏在少数问号砖中，**持续 10 秒**，可以直接撞倒巡逻怪和食人花。落坑和时限仍然有效。
- 每枚金币 100 分，顶碎普通砖 50 分。踩敌时保持腾空能把连击从 100 分逐步提高到 8000 分，踢出的龟壳也能累积连击。
- 触旗按高度计 100、400、800、2000 或 5000 分。滑下旗杆后，计时器上每剩 **1 秒加 50 分**。结算列出冒险得分、旗分、余时和整段行程的总分。
- 钻管往返会保留两边的道具和得分。体力耗尽或时间到后，可在最近点亮的中途旗重试，恢复当时的分数、道具、开闸状态与剩余时间。也可以选择从起点重开本关。
- 选「进入下一关」会带上形态与累计得分。从大厅单独选关会开始新的计分行程。通关后，本浏览器会保存已发现的密室、积分星位置、各难度单关最高分、最快用时和行程最高分。V4 与 V3 共用同一浏览器里的存档。

## 发布到 GitHub Pages

1. 解压 GitHub Pages 发布包，把 `index.html`、`style.css`、`js/`、`assets/`、`.nojekyll` 和说明文件放入仓库的 `main` 分支根目录。
2. 在仓库 **Settings → Pages → Build and deployment** 中选择 **Deploy from a branch**。
3. 选择 **main** 与 **/(root)**，保存设置，等该页出现 **Visit site** 后即可打开游戏。

站点免构建，资源使用相对路径，可以部署在仓库子路径下。[GitHub Pages 官方设置说明](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## 本版制作提示词

> 为八关分别设计一件玩家必须学会的事。花田让玩家选路，果园让玩家接弹簧，晶湖让玩家等船换乘，矿井要求先向左上方折返开闸。让云龟的卵能落在上层平台，让炮口高度决定哪层甲板危险。把库霸的落点画在地面，给每个重跳和冲锋留一个短反击窗口。用完整的正常操作回放校准每关的专家时限。

所给 TAS 视频在约 1:10 与 1:23 分别展示刺卵落到地面与高砖后孵化，约 3:12 展示不同高度的平射炮弹，约 3:45 可见双层砖梁间的锤子兄弟，约 4:56 可见库霸在桥上腾空。本版据此设计四类敌人的行动方式和库霸的新战斗节奏。音乐沿用素材库中的地上、地下、城堡和无敌主题。音画来源及公开分发授权情况见[素材说明](./CREDITS.md)。
