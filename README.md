# 超级玛丽 · 蘑菇王国大冒险

一个中文像素横版平台游戏的四版合辑，收录 V1 至 V4。穿过草甸、晶洞、云海和熔岩城堡，沿途收集星星，最后迎战库霸。每个版本都提供八个可直接选择的主关、休闲／经典／专家三档难度，以及键盘和手机触屏操作。

## 开始游玩

在部署好的网站打开首页，选择任意版本。离线游玩时，下载并解压完整仓库，用浏览器打开根目录的 `index.html`。游戏不需要安装依赖或联网，记录保存在当前浏览器。

| 操作 | 键盘 |
| --- | --- |
| 左右移动 | ← / → 或 A / D |
| 跳跃 | 空格或 J，按住跳得更高 |
| 加速 | 移动时按住 Shift 或 K |
| 蹲下、钻管（V2 至 V4） | ↓ 或 S |
| 攀藤（V2 至 V4） | 靠近藤蔓时按 ↑ 或 W |
| 发射火球（V2 至 V4） | 火焰形态下按 X 或 F |
| 骑龙吞敌／下龙（V4） | X 或 F 吞敌，按住 ↓ 再按 X 下龙 |
| 暂停／继续 | Esc 或 P |

## 部署到 GitHub Pages

把本目录的全部内容提交到仓库的 `main` 分支根目录。在 GitHub 的 **Settings → Pages** 中选择 **Deploy from a branch → main → /(root)**，保存后使用同页的 **Visit site**。根目录是版本选择页，V1、V2、V3 和 V4 的入口依次位于 `v1/`、`v2/`、`v3-original/` 和 `v4/`。部署要求和可见范围以 [GitHub Pages 官方说明](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)为准。
