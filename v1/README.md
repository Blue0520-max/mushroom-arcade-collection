# 超级玛丽 · 蘑菇王国大冒险

在浏览器里踏上草台、乘坐升降晶石、穿越云海，最后闯入库霸的王座。四个世界共八关，每关藏有三枚星币。所有世界从一开始就能进入。

## 开始游玩

解压完整项目，用浏览器打开 `index.html`，点击「开始冒险」。要直奔库霸，可以选择「熔岩城堡」里的「4-2 库霸的王座」。所有图片、音效、脚本和字体都随包提供。

| 操作 | 键盘 | 触屏 |
| --- | --- | --- |
| 左右移动 | ← → 或 A / D | 左右方向键 |
| 跳跃 | 空格、W、↑ 或 J，按得越久跳得越高 | 按住跳跃键 |
| 奔跑 | 移动时按住 Shift 或 K | 同时按住方向与奔跑键 |
| 暂停 / 继续 | Esc 或 P | 右上角暂停键 |

方向、跳跃和奔跑可同时输入。进入后台会自动暂停。支持全屏的浏览器会在暂停键旁显示全屏按钮。

## 冒险路线

| 世界 | 两个关卡 | 玩法 |
| --- | --- | --- |
| 01 青葱草甸 | 初晴小径、弹簧花园 | 顺着金币弧线练习跳跃，踩弹簧探索高处的花园，踢出龟壳击倒巡逻敌人。 |
| 02 辉光晶洞 | 蓝晶摆渡、回声矿道 | 搭乘升降台，在碎裂的石板坠落前起跳。 |
| 03 云顶风车 | 风车邮路、落日云梯 | 穿过飞龟的巡逻路线，在弹簧高路和低处云桥之间选择。 |
| 04 熔岩城堡 | 熔炉巡廊、库霸的王座 | 通过尖刺与熔炉渡桥，点亮战前的中途旗，进入王座竞技场。 |

大厅可选择休闲、经典和专家难度，初始体力分别为 5、3、2 颗心。难度还会改变敌人速度、受伤后的保护时间、碎台停留时间和库霸的反击窗口。

库霸吸气后会喷火，压低身体后会冲锋。跳过冲锋，等它撞墙、头顶冒星时踩头。体力降低后，它会连续喷出两团火球。击败它后，走到右侧金旗完成终局。

撞击问号砖可以获得金币或蘑菇。吃蘑菇能恢复一颗心，满血时会获得短暂无敌。失足会消耗体力，并回到最近点亮的中途旗。通关后，浏览器会合并这关历次收集的星币，并分别记录三种难度的最佳用时。大厅的「最快单关」显示当前所选难度的纪录。

## 发布到 GitHub Pages

1. 把压缩包解开，将里面的 `index.html`、`style.css`、`js/`、`assets/`、`.nojekyll` 和说明文件放到 GitHub 仓库的 `main` 分支根目录。
2. 进入仓库的 **Settings → Pages**，在 **Build and deployment** 下选 **Deploy from a branch**。
3. 选择 **main** 和 **/(root)**，点击 **Save**。部署完成后，在同一页点 **Visit site** 即可游玩或分享。

这是免构建的静态站。资源使用相对路径，可以放在 `https://用户名.github.io/仓库名/` 这样的项目子路径下。部署方式见 [GitHub Pages 官方文档](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。

## 制作提示词

> 做一座能在桌面和手机上游玩的中文像素街机厅。用蘑菇王国全景作封面，把玩家提供的马里奥精灵与音效放进实际关卡。四个世界各引入一种需要掌握的动作，然后用第二关把它和已有技巧组合起来。给愿意绕路的玩家藏三枚星币，给失足的玩家留中途旗。库霸的每招都要有前兆，让玩家通过观察、躲避和踩头赢得决战。
